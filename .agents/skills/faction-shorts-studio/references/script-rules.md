# 대본 작성 규칙 (30초 1.5배속 전용)

팩션 썰쇼츠의 보이스오버 대본은 TTS 음성 생성 → STT 씬 정렬 파이프라인을 거친다.
이 규칙을 지켜야 정확한 타임코드와 자막 씬 데이터가 생성된다.

---

## 기본 스펙

| 항목 | 값 |
|---|---|
| **최종 영상 길이** | 30초 |
| **TTS 배속** | 1.5배속 |
| **원본 TTS 발화 시간** | 약 45초 (1.5배속 후 30초) |
| **대본 글자 수 (공백 포함)** | 약 350~400자 |
| **대본 문장 수** | 약 12~16문장 |
| **FPS** | 30 |

> 💡 1.5배속 공식: 원본 TTS 길이 × (1 / 1.5) = 최종 길이
> 따라서 45초 × 0.667 ≈ 30초

---

## 문장 분리 규칙

`stt-scene-align`이 문장 단위로 씬을 1:1 매핑하므로, **반드시 문장 단위로 줄을 분리**한다.

```markdown
# 올바른 예 (한 줄에 한 문장)
임신성 당뇨에 걸린 아내 때문에 눈이 돌아간 남편이 있었어.
이 남편 원래 그냥 평범한 회사원이었거든.
근데 아내가 매일 밤 빈 과자 봉지를 핥으면서 울어.
```

```markdown
# 잘못된 예 (여러 문장이 한 줄에)
임신성 당뇨에 걸린 아내 때문에 눈이 돌아간 남편이 있었어. 이 남편 원래 그냥 평범한 회사원이었거든.
```

---

## 숫자 표기 규칙

TTS 엔진이 숫자를 정확히 발음하도록 **한글 발음으로 표기**한다.

| ❌ 숫자 표기 | ✅ 한글 발음 표기 |
|---|---|
| `300만 봉지` | `삼백만 봉지` |
| `46그램` | `사십육 그램` |
| `30분` | `삼십 분` |
| `24시간` | `이십사 시간` |
| `2주` | `이 주` |
| `10곳 중 9곳` | `열 곳 중 아홉 곳` |

## 4단계 서사에 맞춘 대본 구조

```markdown
# 도파민 후킹 (0~3초) — 1~2문장
[뇌 정지 유발 한 줄 + 상황 설정]

# 빌드업과 갈등 (3~13초) — 4~5문장
[회사/개발자의 서사, 결핍·분노·집착, 200% 과장]

# 클라이맥스와 반전 (13~23초) — 4~5문장
[제품 USP의 감각적 포장, 시각적·미각적 타격감]

# 여운과 바이럴 (23~30초) — 2~3문장
[Soft Sell, 품절 대란, 군중심리, 어이없는 현상]
```

## 톤 & 말투 규칙

- **구어체 반말** 사용 — 친구에게 재밌는 썰 풀어주는 톤
- 문어체, 뉴스 톤, 설명 톤 금지
- "~거든", "~인데", "~했대", "~이래" 같은 구어체 어미 적극 사용
- 짧고 리듬감 있는 문장 — 한 문장 최대 30자 이내 권장
- 감탄사, 의성어, 의태어 적극 활용

### 톤 예시

| ❌ 문어체 | ✅ 구어체 반말 |
|---|---|
| "이 제품은 글루텐 프리입니다" | "글루텐? 완전 박멸해버림" |
| "창업자는 어려운 시기를 겪었습니다" | "이 사장님 진짜 망할 뻔했거든" |
| "품절 현상이 발생하고 있습니다" | "삼십 분 만에 서버 터져버림" |

## 직접 CTA 금지 규칙

대본 어디에도 아래와 같은 표현을 사용하지 않는다:

- "프로필 링크에서 구매하세요"
- "쿠팡에서 검색하세요"
- "지금 할인 중이에요"
- "꼭 사세요", "추천합니다"
- 제품 구매 페이지 URL
- 할인율, 쿠폰 코드

---

## 제품명 언급 규칙

- 도파민 후킹 단계에서는 제품명을 **절대 언급하지 않는다**.
- 빌드업 단계에서는 회사명 또는 창업자 이름만 자연스럽게 언급 가능.
- 클라이맥스에서 제품명 **1~2회** 자연스럽게 언급 가능 (썰 흐름 안에서).
- 여운 단계에서 제품명 **1회** 가능 (현상 묘사 맥락에서).

## `script.md` 파일 포맷

```markdown
임신성 당뇨에 걸린 아내 때문에 눈이 돌아간 남편이 있었어.
이 남편 원래 그냥 평범한 회사원이었거든.
근데 아내가 매일 밤 빈 과자 봉지를 핥으면서 울어.
참다 참다 폭발한 남편이 뭘 했냐면.
회사 때려치우고 감자칩 공장을 차려버림.
근데 이게 보통 감자칩이 아니야.
글루텐 당류 트랜스지방 완전 박멸해버린 칩이야.
한 입 깨무는 순간 바삭함이 폭발하는데.
맛이 이상한 건강칩이 아니라 진짜 맛있는 거야.
아내가 처음으로 죄책감 없이 과자를 씹으면서 울었대.
근데 이게 입소문 타면서 대한민국에서 난리가 남.
출시 삼십 분 만에 서버 터져서 이 주 연속 전량 매진.
그 사장님은 아내한테 매일 감자칩 한 봉지씩 챙겨준다고.
```

> **주의**: 위는 예시일 뿐이다. 실제 대본은 리서치한 STORY_TRUTH 기반으로 작성한다.
