# 단일 제품 쇼핑쇼츠 파이프라인

## 목적

한 제품을 홍보하는 9:16 세로 쇼츠 한 편을 만든다.
에이전트가 제품 사실, 카테고리별 특화 전략, 참조 영상의 제작 문법을 결합해 기획하고, 사용자가 영상 생성 도구를 선택·승인한 경우에만 실제 클립을 제작한다.

항상 다음 원칙을 지킨다.

- 한 영상에는 한 제품과 하나의 핵심 문제 해결/가치만 담는다.
- **제품 실물 완벽 일치:** 수집/캡처된 실제 상품 상세페이지 실물 이미지를 `ImagePaths` 최우선 레퍼런스로 사용하여 실제 제품의 디자인·라벨·색상·형태가 왜곡 없이 1:1로 일치해야 한다.
- **인물 일관성 (Model Consistency) 필수:** 인물이 등장하는 모든 씬(비포, 거품 시연, 세안, 애프터 등)에서는 **동일 인물(동일 모델의 얼굴, 이목구비, 헤어스타일, 피부톤)**을 유지해야 한다. 첫 인물 컷을 앵커 레퍼런스로 바인딩하여 전 컷의 캐릭터 일관성을 완벽히 고정한다.
- 기획·분석·카피 작성 주체는 이 에이전트다.
- TTS는 외부 스킬(`tts-generate` → `stt-scene-align`)로 위임한다. 에이전트가 음성을 직접 생성하지 않는다.
- 영상 생성 도구는 사용자가 보유한 환경에 맞춰 선택한다(Kling, Runway, Luma, Hailuo 등). 특정 도구에 종속되지 않는다.
- **적용 대상 (전 카테고리):** 식품/음료, 뷰티/스킨케어, 패션/잡화/모자, 키친/주방, 생활/청소/욕실, 가전/디지털, 여행/아웃도어, 문구/오피스 등.
- 참조 영상에서는 구도, 샷 크기, 손동작, 조명, 편집 리듬만 벤치마킹한다.
- 유료 생성이 발생할 수 있다. 제출 직전에 생성 수량·도구·길이·에셋을 보여 주고 반드시 승인받는다.

## 기본 경로 — 먼저 읽는다

새 상품이 들어오면 다음 두 문서를 **가장 먼저 읽고 기본값으로 삼는다.**
1. [검증된 15초 레시피](references/validated-recipe.md): 6비트 구조, 초 배분, 에셋 연동, 알려진 실패 지점
2. [카테고리별 전략 플레이북](references/category-strategies.md): 식품·뷰티·패션·주방·생활·가전·여행·문구별 훅/시연/사운드/인물 연출 전략
사용자가 다른 길이나 구조를 지정한 경우에만 벗어난다.

## 시작 조건

이미 제공된 정보는 다시 묻지 않는다. 아래가 없을 때만 한 번에 짧게 확인한다.

- 한 제품의 쿠팡·스마트스토어·Amazon URL, 또는 사용자가 직접 제공한 제품 이미지
- 참조 영상: 새 업로드가 없으면 [촬영 문법 가이드라인](references/shooting-guidelines.md)을 기본으로 사용
- 원하는 길이: 기본값 12–15초
- 원하는 결과 수량: 기본값 최종 영상 1편 + 대체 훅 2개

상품 URL이 있으면 [상품 링크·이미지 수집 규칙](references/product-link-ingestion.md)을 읽고
자동 수집을 시도한다. 브라우저 탐색은 최대 2-3분 내로 핵심 상세 컷들을 빠르게 캡처/확보하고, 접근이 막히면 이유와 필요한 보충 이미지만 짧게 요청한다.

## 참조 영상 분석 — 기획보다 먼저

새 참조 영상이 첨부되면 에이전트가 영상을 직접 시청하고 분석한다.
구도·샷 크기·손동작·조명·편집 리듬·전환 타이밍을 직접 파악한 뒤 다음 `REFERENCE_DNA`를 잠근다.

```yaml
REFERENCE_DNA:
  source_facts: [길이, 비율, fps, 전체 프레임 수, 강한 전환 수]
  opening_hook: [0–3초의 화면·행동·카피 기능]
  beat_map: [시간대별 제품 공개, 행동, 결과]
  cadence: [평균 샷 길이, 하드컷, 홀드 길이]
  camera: [샷 크기, 높이, 탑다운·45도·정면 구도, 움직임]
  lighting_palette: [광원, 배경, 색, 대비]
  human_presence: [얼굴·손·상반신 노출 수준]
  product_demo: [제품 등장 → 사용 → 결과]
  captions: [위치, 밀도, 안전영역]
  audio: [보이스오버 리듬, 제품음, 배경음악 여부]
  reusable_rules: [단일 제품 광고로 옮길 고수준 규칙]
  avoid_copying: [브랜드, 상품 목록, 고유 문구, 정확한 배열, 음원]
```

원본이 여러 제품 목록형이어도 목록 구조는 가져오지 않는다.
제품 하나를 보여 주는 각 미니 구간의 촬영 문법만 확장한다.

## 5단계 파이프라인

### Phase 1 — 제품 진실 & 에셋 번들 확보

1. 상품 링크(브라우저 서브에이전트로 대표 이미지 및 상세페이지 내 제품/제형/실제 사용 컷들을 신속히 캡처) 또는 사용자 제공 이미지에서 제품 정보와 실물 이미지를 수집하여 `outputs/{project}/assets/`에 체계적으로 저장한다.
2. `PRODUCT_TRUTH`를 작성한다: 제품명, 식별자, 옵션, 색, 재질, 크기, 외형, 확인된 용도와 주장만 기록.
3. **1x3 다중 에셋 시트(`asset_sheet_*.jpg`) 생성 (완벽한 9:16 비율 보장) & 자동 분리**: 
   - 16:9 가로 캔버스에 1행 3열(1x3) 패널을 나열하면 각 패널의 종횡비가 약 1.69로 쇼츠 규격(9:16 $\approx$ 1.78)과 수학적으로 거의 일치하여 좌우 잘림 없는 초고화질 에셋을 얻는다.
   - 6비트 영상의 경우: 3컷씩 2장(`asset_sheet_1.jpg`, `asset_sheet_2.jpg`)으로 분할 생성한다.
     - `asset_sheet_1.jpg`: 비트 1(결과 훅), 비트 2(비포 대비), 비트 3(제품 히어로)
     - `asset_sheet_2.jpg`: 비트 4(핵심 시연), 비트 5(결과 증명), 비트 6(루프 엔딩+CTA)
   - **빈 슬롯(Blank / Black Panel) 처리 룰**: 4컷, 5컷 등 3의 배수가 아닐 때는 마지막 시트의 남는 패널을 "The remaining panel must be left completely empty as a pure solid black background"로 두어, 자동 크롭 스크립트가 검정 빈 패널을 자동으로 제외하도록 한다.
   - 수집한 실제 상품 이미지를 레퍼런스(`ImagePaths`)로 바인딩하고, 실제 제품 표면의 인쇄 텍스트(브랜드 로고, 제품명)는 원본과 100% 일치하도록 프롬프트에 명시한다.
   - 이후 자동 크롭 스크립트(`crop_asset_sheet.py`)를 실행하여 개별 9:16 에셋들(`assets/cut1_9_16.jpg` ~ `cut6_9_16.jpg`)로 분리 저장한다. (가이드 `asset_sheet.md` 저장)
   ```bash
   python3 .agents/skills/product-shorts-studio/scripts/crop_asset_sheet.py outputs/{project}
   ```
4. 참조 영상이 있으면 직접 시청·분석해 `REFERENCE_DNA`를 잠근다. 없으면 [촬영 문법 가이드라인](references/shooting-guidelines.md)을 따른다.
5. 제품 카테고리(식품, 뷰티, 패션, 주방, 생활, 가전, 여행, 문구 등)를 판별하고 [카테고리별 전략 플레이북](references/category-strategies.md)을 매핑한다.
6. 핵심 가치와 눈으로 증명 가능한 행동 하나를 선택한다.
7. 카테고리별 전략에 맞춘 훅 3종(문제 해결형, 비포·애프터형, 질감/ASMR형)을 제안하고 가장 강한 하나를 기본안으로 표시한다.

**첫 컷은 완성된 결과물부터 보여 준다.** 제품 공개는 최소 3초 뒤로 민다.
가격·할인율·판매량·후기 수·성능은 확인된 경우에만 사용한다.

---

### Phase 2 — 15초 6비트 촬영 플랜 & 대본

최종 영상 한 편에 아래를 작성한다.

- 제품, 한 문장 가치 제안, 핵심 시청자, 게시 채널
- **6비트 타임라인**과 총길이 — 각 비트를 정수 초로 고정하고 합이 목표 길이와 정확히 일치하게 설계 (기본: 3+2+2+4+2+2 = 15초)
- 각 비트의 구도: 탑다운·45도·정면 클로즈업 중 기능에 맞는 선택
- 각 비트에 연결할 **에셋 컷 번호** (1–5번 중)와 손 동작 사이즈 매칭
- 한 비트당 한 가지 손동작과 현실적인 결과
- **영상 생성 프롬프트 (`prompts.md`)**: 각 비트별 **매칭 보이스오버 대본 문장**, **실제 음성 싱크 타임코드**, **연결 에셋 파일명**, **구도 및 I2V 프롬프트**를 1:1로 함께 기재
- **보이스오버 대본 (`script.md`)**: TTS 위임용 대본 작성
  - 숫자는 한글 발음으로 표기 (예: `46그램` → `사십육 그램`)
  - 문장 단위로 줄 분리 (stt-scene-align이 씬을 1:1로 매핑)
- 후반에 입힐 한국어 자막 큐와 타임코드 표
- 썸네일 카피, 제목, 설명, SEO 태그 10개, 틱톡·인스타그램·유튜브 쇼츠 문구

생성 모델에 한국어를 직접 그리게 하지 않는다.
화면 상단 중앙에 자막 안전영역을 남기고, 정확한 문구는 편집용 자막 큐로 분리한다.

---

### Phase 3 — TTS 위임 (사용자 실행)

이 단계는 **사용자가 직접 실행**한다.

1. Phase 2에서 작성한 `script.md`를 `outputs/<프로젝트명>/` 폴더에 저장한다.
2. `tts-generate` 스킬로 보이스오버를 생성한다. (로컬 Qwen3-TTS, 1.2배속 후처리)
3. `stt-scene-align` 스킬로 `output_1.2x.wav`와 `script.md`를 정렬해 `scene_data.json`을 만든다.
4. `scene_data.json`의 각 씬 길이를 확인하고 Phase 2의 6비트 초 배분과 맞는지 검토한다.
5. 초 배분이 어긋나면 에이전트에게 알려서 비트 길이를 재조정한다.

```
스킬 경로:
  tts-generate    → .agents/skills/tts-generate
  stt-scene-align → .agents/skills/stt-scene-align
```

### Phase 4 — 영상 생성 & 제품 일치 검수

[영상 생성 워크플로우](references/video-generation-workflow.md)를 먼저 읽는다.

**제출 전 사전점검**

- 에셋 이미지가 9:16으로 패딩됐는가. 정사각 이미지를 그대로 넣으면 비율이 무너진다.
- 각 비트의 길이 합이 목표 길이와 정확히 일치하는가.
- 선택한 생성 도구가 목표 길이를 지원하는가.
- TTS 파일(`output_1.2x.wav`)의 실제 길이를 재고 영상 총길이와 맞췄는가.

실제 생성 전 보여줄 내용:
1. 생성할 클립 수와 각 비트 길이
2. 선택한 도구명과 입력 방식(이미지 기반/텍스트 기반)
3. 비트별 연결 에셋 컷 번호
4. 사용할 손 동작 프롬프트 핵심 문구

생성 결과 검수 항목:
- 제품 색, 형태, 라벨·버튼 위치, 비율, 손 접촉, 배경 연속성
- 에셋 이미지와의 외형 일치 여부
- 생성 글자·워터마크 없음 / 상단 자막 안전영역 확보
- 어긋난 컷은 해당 비트만 재생성한다. 전체를 다시 뽑지 않는다.

### Phase 5 — 최종 조립 & 발행 킷

승인된 클립만 9:16 한 편으로 조립한다.
하드컷·짧은 결과 홀드·보이스오버를 적용하고, 마지막 컷을 첫 컷과 같은 앵글로 두어 루프를 건다.

**자막은 렌더에 포함되지 않는다.**
`scene_data.json`의 씬별 타임코드로 자막 큐 표를 만들어 사용자 편집기로 위임한다.

발행 킷 포함 항목:
- 유튜브 쇼츠·인스타 릴스·틱톡용 썸네일 카피
- 제목 (문제·결과 중심)
- 설명 (확인된 장점 + 링크 위치)
- SEO 태그 10개
- 플랫폼별 본문 문구 3종
- 자막 타임코드 표

## 프롬프트 합성 순서

모든 샷 프롬프트는 아래 블록을 순서대로 쌓는다.

1. `PRODUCT_TRUTH`: 확인된 제품 외형·옵션·기능
2. `ASSET_BINDING`: 비트별 에셋 컷 번호와 반드시 유지할 특징
3. `REFERENCE_DNA`: 구도·조명·손 중심 연출·편집 리듬
4. `SHOT_BEATS`: 시간대별 한 가지 손동작과 결과
5. `HAND_SCALE_RULE`: 에셋 사이즈에 따른 손 동작 크기 제약
6. `CAMERA_LIGHT`: 탑다운·45도·정면 클로즈업, 밝은 중성 생활공간
7. `CONTINUITY`: 제품 색·형태·라벨·버튼·크기·손·공간 일관성
8. `CLEAN_PLATE`: 생성 글자·가격표·워터마크 없음, 자막 안전영역
9. `AUDIO_PLAN`: 제품음·ASMR·별도 한국어 보이스오버 (외부 TTS)

실제 템플릿은 [단일 제품 콘텐츠 시스템](references/content-system.md)을 따른다.

## 최종 인도물
