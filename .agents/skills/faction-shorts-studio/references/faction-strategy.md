# 4단계 팩션(Faction) 서사 전략

대놓고 "이거 사세요" 하면 바로 스와이프 당한다.
철저하게 **'재밌는 이야기'로 위장**해서 끝까지 보게 만들고, 시청자가 스스로 제품을 검색하게 만드는 것이 목표다.

---

## 1단계: 도파민 후킹 (0~3초) — 뇌 정지 유발

가장 중요한 구간이다. 익숙한 대상(브랜드, 사람)에 극단적인 상황이나 감정을 붙여서 시청자의 뇌 정지를 유발한다.

### 공식

```
[대중적인 키워드/브랜드] + [부정적 감정/극단적 행동] + [궁금증 유발]
```

### 전략

- **절대 제품의 스펙으로 시작하지 않는다.** 분노, 광기, 집착, 파멸 같은 자극적인 키워드를 던진다.
- 시각적 소스도 가장 자극적이거나 상황에 딱 맞는 밈(Meme)이 들어가야 한다.
- 3초 안에 "뭐지?" 반응을 끌어내지 못하면 실패.

### 예시 패턴

| ❌ 하지 말 것 | ✅ 할 것 |
|---|---|
| "다이어트 간식 추천" | "임신성 당뇨 걸린 아내 때문에 눈 돌아간 남편의 광기" |
| "이 화장품 좋아요" | "피부과 의사가 자기 브랜드 때려치우고 이걸 바르기 시작한 이유" |
| "맛있는 감자칩" | "감자칩 만들다가 파산 직전까지 간 남자의 집착" |

### 금지 사항

- 제품명 직접 언급 금지
- 가격/할인 정보 금지
- "추천합니다", "꼭 사세요" 같은 직접 CTA 금지

---

## 2단계: 빌드업과 갈등 (3~13초) — 회사/개발자의 서사 (과장 200%)

후킹으로 잡은 시선을 스토리로 묶어두는 단계다. 제품을 만든 사람(회사, 사장님 등)이 얼마나 미친 사람인지, 혹은 어떤 어이없는 위기에 처했는지 **'갈등 상황'**을 묘사한다.

### 전략

- 평범한 제품 개발 과정에 **'서사'**를 부여한다.
- 실패, 빡침, 우연한 사고가 최고의 소재.
- 시청자는 제품이 아니라 **'이 미친 상황이 어떻게 끝날까?'**라는 서사에 몰입하게 된다.

### 스토리텔링 기법

| 기법 | 설명 | 예시 |
|---|---|---|
| **결핍/분노** | 기존 제품이 다 쓰레기 같아서 직접 만듦 | "시중 제품이 전부 다 구리다고 빡쳐서 공장 하나 차림" |
| **집착/광기** | 하나 만들려고 전 재산 투입 | "이거 하나 만들겠다고 아파트 팔아서 스위스 공장 날아감" |
| **우연/사고** | 실수나 우연으로 대박 발견 | "실험실에서 실수로 엎질렀는데 그게 대박 배합이었음" |
| **위기/파멸** | 망할 뻔한 위기에서 역전 | "투자 다 날리고 마지막 남은 돈으로 한 판 더 걸었는데..." |

### 6씬 기준 분할 (씬 2 + 씬 3)

- **씬 2 (5초)**: 갈등의 시작 — 결핍/분노/위기의 배경 설명
- **씬 3 (5초)**: 갈등의 심화 — 집착/광기/파멸 직전의 극단적 상황

---

## 3단계: 클라이맥스와 반전 (13~23초) — 제품의 극적인 등판

제품의 장점(USP)을 서사의 **'해결책'**이나 **'반전 결과'**로 둔갑시켜서 보여준다.

### 전략

- 제품 스펙을 나열하지 않는다.
- **시각적·미각적 타격감**이 느껴지는 언어로 포장한다.
- 앞서 말한 갈등(빡침, 위기)이 이 기적 같은 제품 스펙으로 인해 완벽하게 해소되는 **카타르시스**를 준다.

### 변환 공식

| ❌ 스펙 나열 | ✅ 감각적 포장 |
|---|---|
| "이 젤리는 식감이 좋습니다" | "딱딱함은 사라지고 혀가 녹는 극강의 쫀득함, 한 입 씹자마자 신맛이 폭발해 침샘 풀가동" |
| "건강한 감자칩입니다" | "글루텐, 당류, 트랜스지방을 완벽하게 박멸해버림" |
| "보습력이 좋습니다" | "바르자마자 피부가 물먹은 것처럼 뚝뚝 끊기던 각질이 녹아내림" |
| "가볍고 튼튼합니다" | "깃털처럼 가벼운데 코끼리가 밟아도 안 찌그러짐" |

### 6씬 기준 분할 (씬 4 + 씬 5)

- **씬 4 (5초)**: 반전 시작 — 제품의 극적 등판, USP 시각화 (씨즐 컷)
- **씬 5 (5초)**: 결과 증명 — 감각적 타격감 표현, 디테일 클로즈업

---

## 4단계: 여운과 바이럴 (23~30초) — 구매 유도 없는 구매 유도 (Soft Sell)

"지금 프로필 링크에서 구매하세요" 같은 멘트는 **절대 금물**이다.
철저하게 제3자의 관찰자 시점을 유지하면서 썰을 마무리한다.

### 전략

- 이 제품이 현재 얼마나 대박 났는지, 혹은 얼마나 구하기 힘든지를 **'현상'**으로 전달한다.
- 군중 심리를 자극한다.

### 마무리 공식

```
[어이없는 현상 / 품절 대란 / 예상치 못한 결말]
```

### 예시 패턴

| 유형 | 예시 |
|---|---|
| **품절 대란** | "출시 삼십 분 만에 서버 다운, 이 주 연속 전량 매진이라고" |
| **유명인 효과** | "두바이 부자들이 와인 안주로 박스째 쟁여두고 먹는다고 함" |
| **반전 결말** | "수십억 졸부가 된 사장님은 군인 월급 생각나서 수만 났다고..." |
| **숫자 충격** | "한 달 만에 삼백만 봉지 팔리면서 공장 이십사 시간 풀가동 중" |

### 절대 금지

- "링크는 프로필에", "쿠팡에서 검색", "할인 중" 같은 직접 구매 유도
- 제품 가격 언급
- "구매하세요", "추천합니다" 등 명시적 CTA

### 핵심 효과

시청자는 스토리를 다 즐겼다고 생각하지만, 뇌리에는 제품의 장점과 **'나도 구해서 써보고 싶다'**는 강렬한 결핍이 남는다.
스스로 댓글창을 뒤져서 제품명을 찾게 만드는 **찐 바이럴**이 시작된다.
