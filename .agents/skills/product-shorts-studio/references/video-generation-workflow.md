# 영상 생성 워크플로우 — 도구 불가지론적 가이드

이 문서는 실제 영상 클립을 생성할 때 적용하는 규칙이다.
특정 도구에 종속되지 않는다. 사용자가 보유한 환경(Kling, Runway, Luma, Hailuo, Sora 등)에 맞춰 선택한다.

---

## 1. 생성 경로 선택

먼저 보유한 에셋과 목표에 따라 입력 경로를 결정하고 나서 도구를 고른다.

| 에셋 상황 | 권장 경로 | 주요 도구 예시 |
|---|---|---|
| 9:16 패딩된 에셋 이미지 보유 | **Image-to-Video (I2V)** | Kling, Runway Gen-3, Luma Dream Machine, Hailuo |
| 같은 제품의 여러 각도 이미지 | **Multi-ref I2V** | Kling Multi-Image, Runway Multi-Reference |
| 이미지 없음 (저하 모드) | **Text-to-Video (T2V)** | Kling, Sora, Runway (권장하지 않음) |
| 기존 클립에 모션 추가 | **Video-to-Video / Extend** | Runway Extend, Kling Extend |
| 15초 초과 또는 멀티씬 조립 | **편집 도구로 클립 조립** | CapCut, Premiere, Remotion |

**제품 일관성이 중요한 쇼핑쇼츠는 반드시 이미지 기반(I2V) 경로를 우선한다.**
텍스트 기반(T2V)은 에셋 경로가 완전히 막혔을 때만 사용하고, 사용자에게 품질 저하를 명시한다.

---

## 2. 에셋 이미지 기반 생성 (권장 경로)

### 비트별 에셋 연결 (1:1 직관적 매칭)

각 비트 번호와 동일한 번호의 에셋 이미지(`Cut 1`~`Cut 6`)를 I2V 모델의 첫 프레임(Image Input)으로 사용한다.

| 비트 번호 | 에셋 파일명 (1:1 매칭) | 컷 명칭 & 역할 | 촬영 구도 | 생성 초 |
|---|---|---|---|---|
| **비트 1 (오프닝 훅)** | `cut1_result_9_16.jpg` | **Cut 1 (Result / Hook)** | 45도 또는 정면 매크로 클로즈업 | 3초 |
| **비트 2 (비포 대비)** | `cut2_before_9_16.jpg` | **Cut 2 (Before / Problem)** | 같은 앵글 하드컷 | 2초 |
| **비트 3 (제품 공개)** | `cut3_hero_9_16.jpg` | **Cut 3 (Hero / Product)** | 정면 고정 미세 푸시인 | 2초 |
| **비트 4 (핵심 시연)** | `cut4_action_9_16.jpg` | **Cut 4 (Action / Detail)** | 탑다운 또는 45도 | 4초 |
| **비트 5 (결과 재훅)** | `cut5_proof_9_16.jpg` | **Cut 5 (Re-Hook / Proof)** | 타이트 클로즈업 | 2초 |
| **비트 6 (루프 엔딩)** | `cut6_anchor_9_16.jpg` | **Cut 6 (Loop / Anchor)** | 비트 1 동일 앵글 packshot | 2초 |

### 에셋 사이즈 × 손 동작 키워드

에셋 이미지 속 제품의 화면 점유 크기(소형/중형/대형)에 따라 프롬프트 손 동작 키워드를 다르게 쓴다.
자세한 기준은 [콘텐츠 시스템 에셋 사이즈 규칙](content-system.md#에셋-사이즈--손-동작-매칭-규칙)을 따른다.

---

## 3. 생성 전 사전점검 (제출 전 반드시 확인)

- [ ] 모든 에셋 이미지가 9:16으로 패딩됐는가
- [ ] 각 비트 길이 합이 목표 길이와 정확히 일치하는가 (정수 초 배분)
- [ ] 선택한 도구가 목표 길이를 지원하는가 (최소 2초부터 지원 여부 확인)
- [ ] TTS 파일(`output_1.2x.wav`)의 실제 길이를 재고 영상 총길이와 맞췄는가
- [ ] 6개 비트를 동일 모델로 생성할 계획인가 (모델이 다르면 톤이 어긋난다)

---

## 4. 유료 생성 승인

실제 생성을 발사하기 직전에 다음을 보여 주고 사용자 승인을 받는다.

- 생성할 클립 수와 각 비트 길이
- 선택한 도구명과 입력 방식 (I2V / T2V)
- 비트별 연결 에셋 컷 번호
- 총 예상 비용 또는 크레딧 소모량 (알 수 있는 경우만)

승인 없이 유료 생성을 진행하지 않는다.

---

## 5. 단일 비트 클립 생성 원칙

- 한 비트에서 손동작은 **하나만** 지정한다.
- 복잡한 동작은 3–5초짜리 한 동작 클립으로 나눠 생성하고 편집 단계에서 조립한다.
- 모든 비트는 동일 제품·동일 옵션·동일 외형을 유지한다.
- 생성 도구가 특정 최소 길이(예: 4초)를 요구한다면 2초 비트를 만들 수 없다.
  → 2초 이하 비트는 그보다 긴 클립으로 생성하고 편집에서 트림하거나, 해당 비트 길이를 재설계한다.

---

## 6. 생성 결과 검수

생성 결과를 직접 열 수 없는 경우 검수했다고 말하지 않는다.
아래 체크리스트를 사용자에게 넘기고 판정을 받는다.

**에셋 매칭 검수**
- 각 비트의 생성 결과가 지정된 에셋 컷과 같은 제품인가
- 에셋 이미지의 색·형태·로고·버튼 위치가 영상에서 유지됐는가

**손 동작 검수**
- 손가락 5개가 모두 보이는가
- 손과 제품의 물리적 접촉이 명확히 보이는가
- 에셋 크기 분류에 맞는 손 동작 범위인가 (소형/중형/대형)

**전체 영상 검수**
- 생성 글자·워터마크 없음
- 상단 25% 자막 안전영역 확보
- 배경·조명의 비트 간 연속성
- 비트 1과 6의 앵글·소품 일치 (루프 확인)

어긋난 컷은 해당 비트만 재생성한다. 전체를 다시 뽑지 않는다.

---

## 7. 최종 조립

비트 단위 클립들을 영상 편집 도구(CapCut, Premiere, Remotion 등)로 이어붙인다.

- 하드컷 위주. 트랜지션 이펙트는 사용하지 않는다.
- `output_1.2x.wav` 보이스오버를 0.2초 오프셋에 배치한다.
- 비트 4 시연 구간에 실제 동작음을 보이스오버 대비 −6dB로 믹스한다.
- 마지막 CTA 구간(비트 6)은 무음으로 둔다.
- 자막은 `stt-scene-align`의 `scene_data.json`을 기반으로 편집기에서 얹는다.

---

## 8. 비용·로그

- 생성 전 크레딧 잔액을 확인할 수 있는 경우 확인한다.
- 이 쇼츠 캠페인에서 사용한 크레딧과 성공·실패 클립 수만 집계한다.
- 다른 작업의 사용량을 섞지 않는다.
- 조회할 수 없는 단가나 매출을 임의로 만들지 않는다.

---

## 9. 알려진 도구별 주의사항

> 이 내용은 2026년 8월 기준이며, 도구 업데이트에 따라 달라질 수 있다.

| 도구 | 주의사항 |
|---|---|
| **Kling** | I2V 최소 길이 확인 필수. 이미지 비율이 출력 비율에 영향을 줄 수 있음 |
| **Runway Gen-3** | 최소 길이 4초인 경우 2초 비트 생성 불가. 16:9가 기본이므로 9:16 명시 필수 |
| **Luma Dream Machine** | 모션 정확도가 낮을 수 있음. 시연 비트보다 홀드·결과 비트에 적합 |
| **Hailuo** | 제품 외형 유지력 확인 필요. 첫 프레임과 마지막 프레임 앵커 활용 |
| **Sora** | T2V 품질 우수하나 제품 일관성은 I2V보다 낮음. 저하 모드에서만 사용 |
